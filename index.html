商品评论情感分析系统

面向电商 / 用户运营岗位场景：批量分析商品评论，输出好评率、好评关键词、差评集中维度与可落地的运营改进建议，把人工"翻评论"变成结构化的用户声音报告。Python 标准库实现，零第三方依赖。

查看分析报告 → GitHub 源码

分析链路

导入评论 CSV→ 正/负词典匹配→ 否定窗口反转→ 程度副词加权→ 评价维度归集→ 报告+改进建议

输入只需电商后台导出、含"评论"列的 CSV；词典可按品类持续扩充，分析框架无需改动。

核心能力

  • 情感判定：正/负情感词典 + 否定词窗口反转（"不打滑"正确识别为好评）+ 程度副词加权（"太硬"权重更高）
  • 工程细节：否定作用域以标点为界（逗号后内容不被误反转）；长词优先匹配，避免"严重"中的"重"被误判
  • 维度归集：尺码鞋楦 / 脚感缓震 / 外观做工 / 质量耐久 / 物流包装 / 价格 / 客服 / 抓地安全，8 大维度定位问题
  • 动作导向：差评不只计数——尺码问题→详情页加尺码表，质量问题→批次抽检+主动售后召回，逐维度给改进动作
  • 双格式输出：Markdown 存档 + 可视化 HTML 报告（情感分布、关键词、维度条形、差评卡片）

报告样例（35 条跑鞋演示评论）

42.9%好评 15 条
11.4%中评 4 条
45.7%差评 16 条

用户夸：

不错×3轻×2好看×2舒服×2不打滑×1

典型差评：

“尺码严重不准，偏大很多，退换货很麻烦” → 尺码/鞋楦维度
“开胶了，才穿两周就出现质量问题，生气” → 质量耐久维度
“下雨天鞋底打滑，差点摔跤，抓地太差” → 抓地/安全维度
