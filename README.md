# 商品评论情感分析

电商用户运营工具：批量分析商品评论，输出好评率、好评关键词、差评集中维度和运营改进建议，把"翻评论"变成结构化的用户声音报告。

- **在线演示（项目介绍 + 分析报告）**：https://46bzvs7m64-gif.github.io/review-sentiment/
- **直接看报告**：https://46bzvs7m64-gif.github.io/review-sentiment/sentiment_report.html

## 功能（Python 3，零第三方依赖，词典法）

- 情感判定：正/负情感词典 + 否定词窗口反转（"不打滑"正确识别为好评）+ 程度副词加权（"太硬"权重更高）
- 工程细节：否定作用域以标点为界（逗号后的内容不被反转）；长词优先匹配，避免"严重"里的"重"误判
- 维度归集：尺码鞋楦 / 脚感缓震 / 外观做工 / 质量耐久 / 物流包装 / 价格 / 客服 / 抓地安全
- 输出：控制台报告 + `sentiment_report.md`（含差评原文和分维度改进建议）

## 使用

```bash
python sentiment.py
python sentiment.py --input 你的评论.csv --product 商品名
```

输入只需含"评论"列的 CSV（电商后台导出格式即可）。

## 数据说明

`demo_comments.csv` 为 35 条跑鞋演示评论（含五星好评与典型差评）。词典法的优势是零依赖、结果可解释、可直接按品类扩词典；局限是对网络新词和反讽识别弱，生产环境可换预训练模型，分析框架不变。

## 面试可讲

- 评论分析的产出不是"好评率"一个数，而是定位问题维度：尺码差评 → 详情页加尺码表，质量差评 → 批次抽检+主动售后
- 为什么不用第三方库：演示词典法的完整链路（分词匹配、否定、程度、维度），讲得清原理比调包更重要
